Backup flames

The CSS flame that takes over when the WebGL flame simulation cannot run. It reads a NASA test the same way the simulation does: gravity sets the shape, NASA's recorded outcome switches it off (only at 0 g, where the test ran), more oxygen makes it hotter and shorter, lower pressure makes it wider and softer. To see it inside the simulation, open temp/flame-sim/?css.
